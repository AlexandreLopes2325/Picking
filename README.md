📖 Sobre o projeto

Este repositório hospeda o Guia Geral de Picking da Mellone: um documento operacional, visual e responsivo, que padroniza o passo a passo da separação, conferência e embalagem dos pedidos no setor de Expedição.

A página foi pensada para ser consultada tanto no computador da bancada quanto no celular, com seções coloridas por responsável (Líder e Equipe) e um destaque especial para os pontos que mais geram erro — a chamada Zona Crítica.

🔗 Acesse o guia


https://github.com/AlexandreLopes2325/Picking



(Substitua Picking pelo nome real do repositório. O link é fixo: quem salvar uma vez sempre verá a versão mais recente.)

✨ Funcionalidades


🎨 Seções coloridas por responsável — visual distinto para tarefas do Líder e da Equipe.
📑 Índice clicável (TOC) — navegação rápida entre as etapas.
🔍 Zona Crítica — bloco de checklist em destaque com os pontos de conferência obrigatória antes de embalar.
📱 Responsivo — adapta-se a celular, tablet e desktop.
🖨️ Pronto para impressão — layout otimizado caso alguém prefira a versão em papel.
🏷️ Identidade Mellone — logo e paleta da marca aplicados na página.

✏️ Como editar e atualizar

O fluxo de atualização é simples e o link do site nunca muda:


Abrir a pasta do projeto no VS Code.
Editar o arquivo desejado e salvar (Ctrl + S).
No painel Source Control, escrever uma mensagem descrevendo a mudança.
Clicar em Commit & Sync.
Aguardar a publicação concluir (a verificação muda de 🟡 pending para 🟢 success).
Atualizar o site no navegador para conferir.



⏱️ A publicação leva alguns minutos. Sempre confira o resultado no link antes de avisar a equipe.



🚀 Deploy

O site é publicado automaticamente pelo GitHub Pages a partir da branch main (raiz do projeto). Qualquer alteração enviada (push) ao repositório dispara uma nova publicação.

Configuração: Settings → Pages → Deploy from a branch → main → / (root).

🧹 Boas práticas de manutenção


Manter sempre juntos index.html, styles.css e a pasta img-picking/ — separá-los quebra o estilo ou as imagens.
Usar caminhos relativos nos arquivos (ex.: styles.css, img-picking/logo.png).
Testar o link após cada atualização antes de divulgar.
